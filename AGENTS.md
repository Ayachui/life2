# ЖИЗНЬ — точка правды для агентов

Не верь локальному checkout, прошлому чату и `package.json`.
Игра на проде и на GitHub может быть на десятки коммитов впереди.

## Перед любой задачей

```
git fetch origin
git status -sb
git log --oneline HEAD..origin/main
```

- Если `behind origin/main` — **не описывай состав игры по локальным файлам**.
- Версию, зверей, баланс и тексты читай так: `git show origin/main:js/data.js`
- Движок: `git show origin/main:js/engine.js`
- Если нужно править код на актуальной базе — сначала обновись от `origin/main` (stash/перенос своих правок). Не наслаивай фичи на отставший `0.6.x`.

## Единственные источники

| Что | Где | Не источник |
|-----|-----|-------------|
| Версия в меню | `LIFE_DATA.gameVersion` в `js/data.js` на **origin/main** | `package.json` (`2.0.0` — это пакет, не игра), чаты, скриншоты |
| Состав зверей и мутаций | `js/data.js` + `js/engine.js` на **origin/main** | эмодзи на скрине, старые транскрипты |
| Прод | `origin/main` → Vercel (`life.tzunki.com`) | локальный `World` без `git fetch` |

## Как крутить версию

В `js/data.js`, поле `gameVersion` (`stage` / `major` / `minor` / `patch`):

- тексты, мелкий баланс, багфикс → `patch +1`
- механика, зверь, режим, крупный ребаланс → `minor +1`, `patch: 0`
- стабильный релиз → `major: 1`, `stage: "release"`

База для плюса — **номер на origin/main**, не то, что лежит в неоттянутой копии.
Пример: на проде Альфа **0.11.0**, новый зверь или крупная механика → **0.12.0**, не 0.7.0.

## Конец сессии — всегда на прод

Это правило проекта **перекрывает** «не коммить, пока не попросили».

После любой работы, которая меняет файлы (локальный чат, облачный агент, любая ветка):

1. `git fetch origin`
2. `git rebase origin/main` (если отстали). Конфликты — разреши, не `--force`
3. `git add` без секретов (`.env`, `credentials.json`, ключи)
4. `git commit` с сообщением про «зачем»
5. `git push origin HEAD:main`

Прод = **push в `origin/main`**. Не оставляй только PR и не считай работу законченной, пока `origin/main` не обновлён. Vercel подхватывает `main` сам.

Нельзя: `--force` / `--force-with-lease` в `main`, `--no-verify`, пустой коммит, секреты.

Хук `.cursor/hooks/ship-to-prod.cjs` на `stop` / `sessionEnd` — страховка, если агент забыл. Хорошее сообщение коммита всё равно пишет агент.

## Облачные агенты и локальные

Облачный агент работает в своём клоне/ветке от GitHub. Локальный — в том, что открыто в Cursor.
Они не делят память. Общий канон — **этот файл + origin/main**. После смены состава игры или версии обнови этот файл в том же коммите на `main`.

# ЖИЗНЬ — точка правды для агентов

## Закон

1. **Одна ветка — `main`.** Не создавай `cursor/*`, feature-ветки, форки «на всякий случай». Облачный агент, если среда всё же вывела в ветку, сразу вливает её в `main` и удаляет ветку.
2. **Версия сейчас — Альфа 0.11.0.** Живёт только в `LIFE_DATA.gameVersion` на `origin/main`. Не 0.6, не 0.7, не 0.12 с локальной копии. Новый номер — только когда на `main` реально вышла следующая версия.
3. **Прод = `origin/main`.** Перед работой влей origin в main. После работы запушь `main`. PR не считается финалом.

## Перед любой задачей

```
git fetch origin
git checkout main
git merge origin/main
git status -sb
```

Нужен fast-forward. Если не выходит — остановись, не `--force`.

Не описывай состав игры по неоттянутым файлам. Канон: `js/data.js` и `js/engine.js` **после** merge `origin/main`.

## Единственные источники

| Что | Где | Не источник |
|-----|-----|-------------|
| Версия | `LIFE_DATA.gameVersion` на `origin/main` (закон: **0.11.0**, пока не смените на main) | `package.json`, чаты, скрины |
| Звери и баланс | `js/data.js` + `js/engine.js` на `origin/main` | старые транскрипты, эмодзи |
| Прод | `origin/main` → Vercel (`life.tzunki.com`) | любая другая ветка |

## Как крутить версию

Только на `main`, от текущего номера на origin (**0.11.0**):

- тексты, мелкий баланс, багфикс → `patch +1` (0.11.1)
- механика, зверь, режим, крупный ребаланс → `minor +1` (0.12.0)
- релиз → `major: 1`, `stage: "release"`

Не бампай «на глаз» с отставшего диска.

## Конец сессии — всегда на прод

Перекрывает «не коммить, пока не попросили».

1. `git fetch origin` && `git checkout main` && `git merge origin/main`
2. Если работала другая ветка — `git merge` её в `main`, затем удали ветку локально и на origin
3. `git add` без `.env` / ключей / `credentials.json`
4. `git commit`
5. `git push origin main`

Нельзя: новые ветки, `--force` в `main`, `--no-verify`, пустой коммит, секреты.

Хук `.cursor/hooks/ship-to-prod.cjs` — страховка. Сообщение коммита пишет агент.
